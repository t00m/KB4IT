# KB4IT 0.9.0

KB4IT now runs on Linux, macOS and Windows, adds search, feeds and a live preview server, and ships as a container image, `.deb` and `.rpm` packages and a GitHub Action. Update if you build sites with KB4IT; read "Before you update" if you maintain your own theme or scripts around `kb4it build`.

- **Cross-platform:** KB4IT installs and builds on macOS and Windows, and supports Python 3.11 to 3.14.
- **`kb4it serve`:** builds the site, serves it locally and rebuilds and reloads the open pages when you save a document.
- **Search:** techdoc, blog and bookshelf have full-text search, with a results page filtered by Category and Tag.
- **Publishing:** with `site_url` in `repo.json`, every build writes `sitemap.xml`, `robots.txt`, canonical and Open Graph tags, and an Atom feed (on by default in blog).
- **Customization:** per-repository template and static overrides, build hooks in Python, extra python-markdown extensions, and build-time code highlighting with Pygments.
- **Linked from:** every document lists the documents that link to it, and `kb4it verify` reports broken links and missing anchors.
- **apphelp versions:** each help version can be built into its own folder, with a version selector in the header.
- **Distribution:** `ghcr.io/t00m/kb4it` container image (amd64, arm64), `.deb` and `.rpm` packages that install offline, and a GitHub Action, `uses: t00m/KB4IT@v0.9.0`.
- **Safer builds:** a page that cannot be made fails the build with exit status 1, the cache is written only after a successful build, the deployer removes only pages KB4IT wrote, and a `target` folder that overlaps the repository is refused.
- **Security:** the bundled themes escape template output, and `"markdown": {"sanitize": true}` cleans the HTML of each document with nh3.

## Before you update

- The bundled themes require KB4IT 0.9.0.
- `kb4it build` exits 1 when any page fails. Scripts that ignored partial failures now stop.
- The lock file moved from `~/.kb4it/var/kb4it.lock` to `var/kb4it.lock` in each knowledge base.
- Custom themes: links in documents are no longer rewritten (the `HTML_TAG_A` transformation is gone), and 115 unused bundled templates were removed. A theme without `"autoescape"` in `theme.json` prints values as before and gets a `THEME_AUTOESCAPE_OFF` warning.
