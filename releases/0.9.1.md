# KB4IT 0.9.1

KB4IT now draws diagrams and math formulas, gives every site a favicon and a 404 page, and ships its help inside the package. Update if you want any of these; existing sites keep building as they are, apart from the dollar-sign rule below.

- **Diagrams:** a code block named `mermaid` becomes a diagram, in all four themes. See the [diagram and formula gallery](https://t00m.github.io/KB4IT/reference-diagrams-formulas.html).
- **Formulas:** `$...$` and `$$...$$` become math formulas drawn with KaTeX. Code blocks and inline code are never changed.
- **Offline:** Mermaid and KaTeX ship with KB4IT and are copied into a site only when one of its pages uses them, so diagrams and formulas work offline and from disk.
- **Favicon:** every page gets one, taken from `logo` in `repo.json` or from the theme.
- **404 page:** techdoc, blog and bookshelf write `404.html`, and `kb4it serve` shows it for missing pages. The help explains how to set it up on nginx and Apache.
- **Help center:** `kb4it help` opens the help that ships with KB4IT, with no network. A notice points to it until you run `kb4it help --dismiss`.
- **Easier start:** `kb4it create` prints the next steps, and the default apps come with sample documents.

## Before you update

- A pair of dollar signs with no space after the first one and none before the second is now a formula. `$5/$10` turns into math; write `\$` for a dollar sign as text. `costs $5 and $10` is not affected. See the troubleshooting entry "Text between dollar signs shows as a formula".
- The bundled themes require KB4IT 0.9.1.
- Custom themes: `theme.json` no longer needs a `version` key, and a theme can name its favicon with the new optional `favicon` key.
