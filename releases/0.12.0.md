# KB4IT 0.12.0

KB4IT 0.12.0 gives themes a public API, lets you name your knowledge bases and work with them from the terminal, and adds a Gallery, a Diagrams page, a calendar and focus mode to techdoc. 0.11.0 was never released, so this release holds everything since 0.10.0. Every site is rebuilt once on its first build.

- **Theme API:** `kb4it.theme` is one module for writing a theme: `class Theme(BaseTheme)`, a list of features and only the hooks you need, which get read-only `Site` and `Doc` objects. `kb4it new-theme` starts a theme from a starter, `kb4it theme-info` shows what a theme is made of, and `kb4it install-theme` and `uninstall-theme` add and remove themes from a zip or a URL. The four bundled themes are written with it and their pages do not change.
- **Project ids and terminal commands:** give a knowledge base a short id (`kb4it build sapblog`) with `kb4it create --id` or `kb4it import`. `kb4it keys` lists properties and values without a build, `kb4it search` finds text in the sources of every knowledge base, and `kb4it delete` removes one from the list. Tab completion works in bash, zsh and fish.
- **Terminal interface:** a Settings Reference with every `repo.json` key of the project's theme, a `repo.json` editor that checks the file before saving, a Themes screen with Install and Uninstall, and mouse selection of text everywhere.
- **techdoc:** a Gallery page for the images and a Diagrams page for the Mermaid diagrams of the documents, both with property filters; an events page with a calendar panel; a filter bar with live counts on the document tables; search and sort on long tables inside documents; a side table of contents with Expand all and Collapse all; a reworked Stats page with totals, coverage and metadata health; Edit in the editor on every document; and a `Degraded` status for work completed with problems.
- **Focus mode (techdoc):** a switch in the top bar hides everything but the title, the document with every section open, and the side table of contents. `"focus_mode": true` in `repo.json` opens every document in focus mode; repositories made with `kb4it create` have it on.
- **Author profiles:** a `PROFILE-<name>.md` file with `ProfileOf: Author` describes a person. Their page shows the profile, document pages show their role and team, and the techdoc quality score checks that the people a document names have a profile.
- **Search engines and sharing:** every page gets schema.org structured data and Open Graph tags. `seo.index` decides whether search engines may index the site, and `kb4it create --index` asks it up front.
- **Link checks:** after every build KB4IT checks the links between the pages and logs each one that points to a missing page or section.
- **Task lists:** `- [ ]` and `- [x]` show as checkboxes in every theme out of the box.

## Before you upgrade

- Every site is rebuilt once on its first build with 0.12.0.
- New dependencies: Pillow, pymdown-extensions and argcomplete. Textual 6.7.0 and rich 14.2.0 or later are required.
- A file named `PERSON-<name>.md` is no longer a profile. Rename it to `PROFILE-<name>.md` and add `ProfileOf: Author`.
- `git_server` must be a full URL, such as `https://github.com`, in every theme. apphelp took a host name until now; with one, the site gets no git links and the build logs `GIT_SERVER_NOT_URL`. In apphelp, `"git"` must be `true`, not `"true"`.
- techdoc now turns on the Atom feed and the side table of contents by default. Turn them off with `"feed": {"enabled": false}` and `"toc_sidebar": false` in `repo.json`.
- techdoc and bookshelf no longer build `help.html`; their Help link opens the KB4IT help site.
- Shared libraries moved to `resources/vendor/` in each website. A template override that links `resources/themes/<theme>/framework/...` for UIkit, highlight.js or DataTables must link `resources/vendor/...` instead.
- Custom themes: the theme API before `kb4it.theme` (`Builder`, `DocumentTheme`, the themekit mixins, `self.srvdtb`) still works but is deprecated. A theme on `DocumentTheme` without its own `build_page()` now runs the page pipeline; set `page_pipeline = False` to keep the old behaviour. A theme without heading templates gets `kb-h2` ... `kb-sect4` wrappers. An override of `PAGE_STATS.tpl` must use `var['stats']`. Imports between modules of a theme's `logic/` folder should be relative (`from .helpers import x`).
- With `"strict": true`, blog sites now also stop on a post-build check warning.
- The bundled themes require KB4IT 0.12.0.
