# KB4IT 0.8.0

KB4IT now has a user guide, and this release fixes several bugs in the terminal interface, the blog theme and the command line. Update if you use the TUI or the blog theme.

- **Help site:** https://t00m.github.io/KB4IT/ explains how to install KB4IT, write documents, build and publish a site, use the four themes and create your own.
- **Terminal interface:** compiling a second project with a different theme no longer uses the first project's theme. A failed build now shows "FAILED" instead of "Done". After a build, Explore, View Build Log and Browse are available without leaving the project.
- **blog:** posts without an `Author` were missing from the home page. They now appear.
- **apphelp:** table columns no longer break words in the middle.
- **Command line:** `kb4it create` with an unknown theme exits with status 1, so scripts can detect it.

Full list of changes: CHANGELOG.md
