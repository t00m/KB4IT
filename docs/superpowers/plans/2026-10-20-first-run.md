# First-run experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new knowledge base from `kb4it create` builds to a site with sample documents, and the command ends with three plain next steps.

**Architecture:** `create` copies each theme's `apps/default/` folder. The samples go into those folders. The next steps are built once in the workflow and read from the app object by the CLI and the TUI, so the terminal and the TUI show the same lines.

**Tech Stack:** Python 3.11+, pytest, Textual (TUI), Mako templates, Markdown with YAML frontmatter.

**Spec:** `docs/superpowers/specs/2026-10-20-first-run-design.md`. Read it before starting. It has the approved defaults.

## Global Constraints

- Never use the em dash character in any text, code, comment or docs.
- Commit each finished task with a one-line Conventional Commits message. No trailers, no attribution lines.
- Never push. Never create a branch or a worktree. Stay on the current branch.
- Run tests with `uv run pytest`. It imports the working tree.
- Samples and help text follow the writing rules in the `nonia` skill: short sentences, plain words, no filler.
- Every sample document must pass its theme's checks (see the theme READMEs in `kb4it/resources/themes/<theme>/README.md`).

## Review Focus

- A user's own file with the same name as a sample is overwritten by `create` when it runs in an existing folder. Expected: the user's file stays. (Task 2)
- A folder path with spaces or non-ASCII characters appears in the next steps. Expected: the full path is printed, copy-paste safe. (Task 1)
- A build after the user deletes every sample succeeds with an empty `source/`. Expected: exit 0, empty site. (Task 2)
- `create` for a theme app without samples (bookshelf before Task 5) prints the same next steps. Expected: the next steps still show; no crash. (Task 1)
- The TUI create path with a parent folder that does not exist still shows the existing error and no next steps. Expected: unchanged error, no next steps. (Task 6)
