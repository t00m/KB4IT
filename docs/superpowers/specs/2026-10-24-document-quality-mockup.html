Static mockup for the spec 2026-10-24-document-quality-design.md. Scores and counts come from the draft model run on the sapbasis-docs repository (1034 documents) on 2026-10-24. Titles are real, except in the banners and the related documents, which are examples. New elements are marked "Proposed" in the source.
