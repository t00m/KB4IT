# Looking back at the year

## Excerpt

Three habits that worked this year, and one change for the next.

## Body

This is a sample post with a date at the end of the year. Posts are listed newest first, so this one opens the home page. Copy it as a starting point, or delete it.

Three things worked well this year:

1. Writing one short note a week, see [A note on backups](reading-note.md).
2. Keeping every note in plain Markdown files, so they are easy to search and move.
3. Publishing the notes as a static site that needs no server software.

Next year the plan is to write fewer, longer posts.
