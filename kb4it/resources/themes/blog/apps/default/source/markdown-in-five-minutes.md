# Markdown in five minutes

## Excerpt

The Markdown you need for nine posts out of ten: text, lists, links, images and code.

## Body

This is a sample post that shows the Markdown you will use most. Copy it as a starting point, or delete it.

### Text

Write **bold** with two asterisks and *italic* with one. Write `code` between backticks.

### Lists

- A dash starts a list item.
- Indent with four spaces for a nested item.

1. A number starts a numbered list.
2. The numbers can all be `1.`; Markdown counts for you.

### Links and images

Link to another post by its file name: [Welcome to my notes](first-post.md). Put images in `source/resources/images/` and show them with `![text](resources/images/name.png)`.

### Code blocks

```bash
kb4it build config/repo.json
```
