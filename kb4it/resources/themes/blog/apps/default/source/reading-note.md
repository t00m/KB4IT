# A note on backups

This is a sample note. Notes use the same `Date` and `Tag` properties as posts, so they also appear in the archive. Copy this file as a starting point, or delete it.

Keep a copy of every backup off the machine it protects. A backup on the same disk does not help when the disk fails.
