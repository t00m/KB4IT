# Troubleshooting

## The document list is empty {#empty-list}

### Cause

The repository folder has no documents, or it was moved.

### Fix

Open the repository again with **Open repository**.

## A rename fails {#rename-fails}

### Cause

Another program has the file open.

### Fix

Close the other program and try again.
