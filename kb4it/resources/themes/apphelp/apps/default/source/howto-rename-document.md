# Rename a document

## Rename one document {#rename}

1. Select the document.
2. Press <kbd>F2</kbd>.
3. Type the new name and press <kbd>Enter</kbd>.

## Undo a rename {#undo}

Press <kbd>Ctrl</kbd>+<kbd>Z</kbd> right after the rename.
