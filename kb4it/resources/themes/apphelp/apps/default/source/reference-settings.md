# Settings

## General {#general}

| Setting | Default | Meaning |
|---|---|---|
| Open last repository | On | Open the last repository at start |
| Confirm deletes | On | Ask before deleting a document |

## Appearance {#appearance}

| Setting | Default | Meaning |
|---|---|---|
| Colour scheme | Follow system | Light, dark or follow the desktop |
