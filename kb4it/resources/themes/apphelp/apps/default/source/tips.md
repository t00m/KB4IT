# Tips

## Keyboard shortcuts {#shortcuts}

<kbd>Ctrl</kbd>+<kbd>F</kbd> searches, <kbd>F2</kbd> renames.

## Search by field {#search-by-field}

Type a field value in the search bar to see every document that has it.

## Undo works for renames {#undo}

Renamed the wrong document? Press <kbd>Ctrl</kbd>+<kbd>Z</kbd>.
