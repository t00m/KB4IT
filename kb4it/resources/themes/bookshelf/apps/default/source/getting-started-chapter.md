# Getting started

This is a sample chapter. Bookshelf places each note on the shelf with `Book`, `Part` and `Chapter`. `Status` shows how far you are, and `Date` sorts the chapters within a part. Copy this file as a starting point, or delete it.

Each chapter is one Markdown document. Put the chapters of a book in the same `source/` folder, and give them the same `Book` value.
